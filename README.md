# AMURA Engine 4

Nueva base limpia del probador AR de muñeca AMURA.

- Origen técnico: runtime estable R18.1.2 de `amura-engine-2`, commit `fc78ef06f1ca19158ebd20337d4652aa848b6d08`.
- El repositorio histórico no es una dependencia de ejecución.
- `app/` contiene únicamente la aplicación y sus assets locales necesarios.
- `dist/` se genera con `npm run build`.
