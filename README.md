# AMURA Engine 4

Base limpia del probador AR de muñeca AMURA.

Estado actual: **ENGINE 4 · R1.1**.

La aplicación es autocontenida y utiliza dependencias locales de MediaPipe, WASM, Three.js, Draco, el modelo GLB del reloj y el banco de pruebas.

No depende de repositorios anteriores durante la ejecución.
